# ZiGVerse Frontend

This folder contains the code for the ZiGVerse Pan-African DeFi dashboard UI.

## Features
- Wallet connection (MetaMask, MathWallet, WalletConnect)
- Real-time prices from oracles
- Token balances and actions (mint, claim, stake, vote)
- NFT and soulbound identity integration
- DAO proposals and voting
- Vault and redistribution visualization
- Modular, mobile-friendly design

## Tech Stack
- Next.js
- Tailwind CSS
- Ethers.js / Wagmi
- Wallet integrations

## Structure
- `/pages` — Main routes (dashboard, identity, tokens, oracles, dao, vault, nfts)
- `/components` — Reusable UI components
- `/lib` — Web3 and contract interaction logic
- `/public` — Static assets (logos, icons)
